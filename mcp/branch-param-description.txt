The branch to search, matched case-insensitively against the branches recorded for each indexed snapshot. Matching also compares the final path segment, so "main" matches a snapshot recorded as "origin/main". Leave this unset in almost all cases: the currently checked-out branch is used automatically. Set it only to search a branch other than the one checked out, for example to look at how a maintenance branch implements something. Ignored when a revision is set. If the requested branch has no indexed snapshot, results fall back to the repository's default branch, so treat results as potentially coming from elsewhere when searching a branch that may never have been indexed.
