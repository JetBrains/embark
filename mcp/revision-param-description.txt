The commit revision to search, as a Git SHA. Leave this unset in almost all cases: by default the search targets the snapshot indexed for the currently checked-out branch, which is what you want when exploring the code you are working on. Only a revision that has already been indexed can be searched, and the match is exact with no fallback — passing a revision that was never indexed returns no results rather than older results. Set it when you deliberately need a different commit than the checkout, for example to compare the current implementation against a specific release commit.
